# Ideas Repository

This repository contains auto-generated documentation from the Idea Operator Bot.

Each idea creates a folder with:
- `IDEA.md` - Problem, user, value proposition
- `PRD.md` - Product requirements document
- `MVP.md` - 7-day implementation plan
